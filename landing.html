Installation Guide

1

Download OptiNetX

Clone or download the OptiNetX repository from the source. git clone https://github.com/Ritwiksri55/ optinetx.git

2

Open Project

Navigate to the project folder and open landing.html in your browser.

cd optinetx
open landing.html
3

Start Planning

Click "Launch Workspace" to access the network planning tool. No installation required!

Learn OptiNetX

🎨 Design Mode

Draw Coverage Areas: Click "Draw Region" and mark the area you want to cover on the map.

Manual Placement: Use "Drop Manual Node" to place routers individually.

AI Auto-Plan: Let the AI automatically calculate optimal router placement.

⚙️ Hardware Settings

Frequency Selection: Choose between 2.4 GHz (longer range) or 5 GHz (faster speed).

TX Power: Adjust transmission power to simulate different router models.

📊 Coverage Analysis

Green Zones: Optimal signal strength

Orange Zones: Weak but usable signal

Red Zones: Interference from overlapping routers

No Color: Dead zones with no coverage

🚀 Deployment Mode

Track Progress: Monitor deployed vs pending routers.

Filter View: Show only deployed or pending nodes.

Work Orders: Manage deployment tasks in the operations table.
